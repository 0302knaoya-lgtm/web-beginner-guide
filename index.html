01 · REACT

画面を部品にして、状態を記憶する

ReactではHTMLに似たJSXを使います。useStateはクリック回数など、変化する値を記憶します。

  • コンポーネント：再利用できる画面部品
  • Props：親から部品へ渡す情報
  • State：操作で変化する情報
Counter.jsx
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);
  return (
    <button onClick={() => setCount(count + 1)}>
      {count}回クリックしました
    </button>
  );
}
02 · NODE.JS

JavaScriptをブラウザの外で動かす

Node.jsを使うと、サーバー処理、ファイル操作、開発ツールの実行ができます。

  • サーバー：リクエストへデータを返す
  • npm：ライブラリを追加・管理する
  • package.json：プロジェクトの設定表
server.js
const http = require("http");

const server = http.createServer((req, res) => {
  res.writeHead(200);
  res.end("Node.jsからこんにちは！");
});

server.listen(3000);
03 · NEXT.JS

ページとサーバーをひとつにまとめる

Next.jsではフォルダ構成がURLになります。Reactの画面とサーバー処理を同じ場所で管理できます。

  • ルーティング：URLごとにページを分ける
  • サーバー処理：安全な場所でデータを扱う
  • 最適化：画像や表示速度を整える
app/about/page.tsx
export default function AboutPage() {
  return (
    <main>
      <h1>私たちについて</h1>
      <p>Next.jsで作ったページです。</p>
    </main>
  );
}

FOLDER = URL

Next.jsのフォルダ構成

App Routerでは、appフォルダ内のpage.tsxがページになります。

app/page.tsx→/
app/about/page.tsx→/about
app/contact/page.tsx→/contact
